# 一片叶子的一生 · 中国茶文化互动长卷

一个可直接托管的静态网站，**中英双语**：`index.html` + `assets/img/` 里的五张本地图片。**双击 `index.html` 即可打开**（需连同 `assets` 文件夹一起），不需要联网、不需要安装、不需要构建。

**线上地址**：<https://lingyuan66524.github.io/tea-leaf-life/>（GitHub Pages，仓库 <https://github.com/LINGYUAN66524/tea-leaf-life>）

右上角的 `EN` / `中文` 按钮切换语言，选择会记住，下次打开保持。切换后整页重载，图鉴与答题进度保留（进度按条目编号记录，不随语言变化）。

图鉴计数只统计有效条目，与格子一一对应；旧版本用名称记录的进度会在首次加载时自动迁移到编号，无效键会被清理，因此不会出现"计数比实际解锁多"的情况。

**更新线上版本**：改完文件后 `git add . && git commit -m "update" && git push`，GitHub Pages 会自动重建。其它托管方式见 [DEPLOY.md](DEPLOY.md)。

## 怎么改内容

打开 `index.html`，搜索 `const DATA_ZH = {` 和 `const DATA_EN = {`。两份数据结构一一对应，所有文案、茶类、器物、茶俗、茶诗、盲品题、斗茶局、40 道题都在里面：

- `teas` —— 加茶类；`pos` 是它在光谱上的目标位置（0–100），两份数据必须一致
- `vessels` —— 二十四器；`s` 是配对用的短标签，`f` 是图鉴里的解释
- `quiz` —— 题目；`l` 是难度（1 识记 / 2 辨认 / 3 情境 / 4 推理），`a` 是正确项下标
- `titles` —— 称号门槛（按答对题数）

界面文案（导航、按钮、提示）在 `applyLang()` 里集中替换，`TX(中文, English)` 用于交互反馈。

样式在 `<style>` 里，配色集中在 `:root` 的 CSS 变量：`--paper` `--ink` `--tea` `--celadon` `--cinnabar`。

## 几个设计取舍

- **不做假的"地图"**：五地茶俗用卡片 + 步骤条，而不是画一张不准确的中国地图。
- **点茶评分是规则判定**，不是物理模拟：速度落在区间内、筅头在中圈，汤花才涨。
- **冲泡分数只表示"离这款茶的标准参数有多远"**，不声称能还原真实风味。
- 所有史料表述以《茶经》《茶录》《大观茶论》及通行茶学教材为据；健康相关只谈饮用体验，不做疗效承诺。

## 兼容性

- 现代浏览器（Chrome / Edge / Safari / Firefox 近两年版本）
- 移动端优先，320px 起可用；支持键盘操作（茶卡可用方向键选位、回车放置）
- 中英双语，切换按钮在右上角，语言偏好存在 `localStorage`
- 尊重系统的"减少动态效果"设置
- 静态文件合计约 700 KB，无任何外部请求
